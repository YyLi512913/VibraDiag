# M1-T03 CSV导入、参数版本与输入确认验证

日期：2026-10-29。范围为后端数据入口子任务，不代表完整M1验收或现场试用。

## 已实现

- 正式 `/api/v1/measurements`：会话/CSRF、上传、授权分页列表、详情与有限波形预览、原CSV下载、revision历史、参数修订、当前输入确认。
- CSV保留原始字节，UTF-8/BOM单列value；32MiB及1024—1000000点限制；不丢弃错误行、不补采样率/单位、不将NaN/Inf变0。不可表示的非零极小值明确拒绝，避免浮点下溢被误当静止信号。
- 参数为完整不可变revision，数据库行锁与预期版本防并发覆盖；输入确认绑定revision和操作者，重复请求返回同一确认，旧确认不能确认新版本。来源声明不是现场真实性证明；参数来源记录保持不可变，确认另表关联，不回写伪造的“已校准”来源。
- 原文件路径由服务端UUID生成；上传暂存、fsync、同卷排他原子发布、DB事务和审计。上传失败清除本次暂存；发布后事务失败的文件作为孤立物保留，避免提交结果不明确时误删有效数据。
- 0006_file_validation迁移记录已校验样本结构，并保护文件hash/大小/路径等身份字段不被改写。文件内容每次正式详情/下载/确认前校验；缺失/损坏返回明确409，不作为有效输入确认。
- 当前资源与历史revision均检查设备范围；管理员无隐含业务访问权。耗时校验后重新检查会话/角色，撤权不能借上传中的旧身份继续落库。
- 导入并发上限2，满时429；原文件32MiB，multipart请求另限32MiB＋64KiB，含无Content-Length请求；元数据字段64KiB，最多1个文件/1个字段。预览最多2000点且保留各桶极值，计算原数据不被预览覆盖。
- 文件对账CLI仅报告引用文件缺失/损坏、未引用原文件及暂存文件，不删除任何文件。
