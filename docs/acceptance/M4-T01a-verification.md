# M4-T01a 正式任务只读工作台验证

2026-11-01。本轮交付共享正式会话、本人任务分页、任务详情及当前授权来源预览；完整M4尚未完成。上游：[M4设计](../11-m4-workbench-design.md)、[M3受限软件验收](M3-acceptance.md)。

## 1. 实现范围

- 数据分析与Agent任务共享登录、退出和会话失效处理；模型实验仍为独立开发入口。
- 只读页面显示状态、执行模式、实际模型/Embedding调用、等待条件、缺项、未发布草稿、调用账本和事件。没有任务时不填充演示结论。
- 读取来源前重新读取任务，核对引用仍属于当前可用草稿，再通过正式授权API取数值结果或知识原文；文本按普通文字渲染。
- 会话修订号、请求序号和AbortController共同阻止迟到响应覆盖新账号。仅可见页面的当前queued/running详情轮询，暂时失败退避至最多10秒。
- 未接创建、回答、恢复、取消、知识管理及报告复核；下一步为M4-T01b。

## 2. 实际验证

[最终前端回执](../../experiments/m4-t01a-frontend-v2.json)：12项真实TypeScript状态测试通过，vue-tsc和Vite生产构建通过；无新增测试框架依赖。覆盖会话切换、迟到登录/列表/详情、隐藏暂停、退避、401/403/404、引用二次核验、卸载、退出CSRF和迟到下载丢弃。

[浏览器回执](../../experiments/m4-t01a-browser.json)：15项本机流程检查通过。使用专用测试数据库、生成的合成账号与信号，真实API、规则执行、数值工具和本地BGE-M3知识索引；关闭Worker以保留排队任务，未调用外部大模型。

| 流程 | 观察 |
| --- | --- |
| 登录及分页 | 本人任务20+8条；另一账号仅见自己的1条 |
| 实际详情 | 基础分析、数值来源、等待信息、拒答、受限完成与缺项均可读 |
| 知识来源 | 发布原文及行号/哈希可读；原文中的script文字未执行 |
| 共享会话 | 切到既有分析页面无须重复登录，历史分析及两张图可读 |
| 活跃任务 | 可见排队详情产生重复真实GET读取 |
| 输入失效 | 专用测试库精确撤销一条本轮输入确认后，刷新隐藏旧草稿与来源 |
| 退出及切号 | 清除前账号数据；最终登录页明确显示“已退出登录。” |
| 窄屏布局 | 390px仿真下响应式header为column、导航wrap，文档宽375px且所检查控件未越界 |

## 3. 限制与证据边界

[桌面中间截图](../../experiments/m4-t01a-workbench.png)已目视检查，展示只读布局；截图之后仅修订了草稿提示和一个缺项中文标签，最终源码以v2回执指纹为准。[初次前端回执](../../experiments/m4-t01a-frontend.json)保留为中间记录。

浏览器在调整仿真视口后截图出现裁切或超时，虽然DOM响应式与边界检查正常，本轮不声明最终窄屏视觉验收通过。退出操作的浏览器诊断出现ERR_ABORTED，同时应用确认退出，API日志记录204；保留该诊断，不按“浏览器零错误”表述。

输入撤销为专用测试库的一次精确故障注入，不是现场操作记录。测试数据、审核授权和账号均为合成软件验证材料，不构成工程师认证、真实工厂试用、独立模型效果或诊断资格。后端业务代码、迁移和默认rules策略未变；沿用M3已有850项全量基线，本轮未重新运行该全量，不新增付费模型测量。M3完整验收及工厂准入仍为false。
