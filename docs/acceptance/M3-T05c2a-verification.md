# M3-T05c2a 方法与比较评测协议及评分器

日期：2026-11-01。范围：T05c2的协议/评分基础设施，不是整个T05c2结项。

## 交付

`backend/config/agent-method-comparison-v1.json`预登记5条方法场景和4条比较场景。方法包含相关资料与干扰、仅不相关资料、无资料、生成中撤回及资料注入；比较包含完整条件、缺少负载容差、相同采集根与重复样本。方法使用既有model_method_v1，比较使用既有规则图，不把规则比较称为模型自主比较。

新增`evaluation/method_comparison.py`，接收运行器标准化后的真实结果与协议标注，分别输出引用完整性、预标注片段命中、拒答、数值、双输入完整性和结论边界。有效逐字引用不自动获得相关性分；即使来自相关资料，也必须包含预标注相关片段。比较不可比时必须没有变化指标，完整条件下RMS预期变化为-50%；NaN、无穷、布尔和错误数值不能通过。维修有效性必须为空。

评分器依赖运行器解析的真实来源、权限与父产物状态；它本身不验证数据库来源真实性。片段匹配仅是受控开发语料评分，不是通用语义判断。缺失标准化字段直接报错，不能默认为通过。

## 验证与后续

新增评分器反例测试，并联跑既有方法模型图及双输入比较集成测试：49项通过，耗时108.66秒，结果见`experiments/m3-t05c2a-tests.xml`。评分器最终版本再次单独复核11项通过，见`experiments/m3-t05c2a-scorer-tests.xml`；两次测试有重叠，不相加为60项独立测试。文档校验通过。本步没有新增真实模型效果结果，不把模拟网关测试计为DeepSeek准确率。

下一步T05c2b：构建带固定原文和相关片段标注的开发语料，通过真实任务API运行上述矩阵；先冻结来源hash、标注和执行配置，再调用真实模型。分别保存检索命中、模型摘录、逐字引用、相关片段与拒答分项，保留失败。比较任务需经Agent任务入口绑定实际双输入回执，并与工具层结果交叉核对。运行器尚未交付，本协议不能被描述为9条实测通过。
