# M3 本机受限Agent软件条件验收

日期：2026-11-01。结论：**受限探索Agent后端在本机软件范围有条件通过，可进入M4工作台开发；M3原始完整验收及工厂试用准入尚未全部通过。**

本记录不修改原M3-AT01—AT05和项目P0。模型/数据资格未闭合的部分继续列为未准入，不以软件测试数量替代四分类、语义或现场效果。

## 1. 已交付范围与候选基线

当前后端提供固定目标的基础分析、轴承探索观察、受控双输入比较和方法资料任务。服务器登记候选及参数，模型只选择候选/明确结束，方法生成只允许逐字摘录；最终草稿保留真实来源、缺项、未发布状态和当前有效性，不自动发布工程报告或创建维修动作。

任务具有身份/输入快照、幂等/CAS、预算/调用账本、持久图、暂停恢复、取消及当前授权检查。知识服务具备MD/TXT版本、显式审核发布/撤回、固定BGE-M3、pgvector精确cosine、权限/发布/向量身份过滤和真实引用绑定。默认仍为rules；显式model_v2分别选择方法/数值v2，新旧配置和图不互相升级。

候选代码是T05c3b实测时冻结的运行时与测试字节，迁移支持到0024_method_model_v2，44张业务表、4张检查点表。当前全量证据为[850项JUnit](../../experiments/m3-t05c3b-tests.xml)，另有57项专项，不能相加。验收脚本逐文件检查该测量的291项指纹，并拒绝未经过全量的业务源码修改/新增；本次仅增加单独测试的验收工具。

本轮新增[验收协议](m3-exit-plan.json)、[只读审计器](../../backend/scripts/m3_acceptance_evidence.py)和[入口脚本](../../backend/scripts/verify_m3_acceptance.py)。其[19项测试](../../experiments/m3-t05d-audit-tests.xml)检查失败/跳过JUnit、无执行选择器、漏映射/重复项、源码漂移、额外未验证源码、错误模型回执、历史失败被替换及资格被误开放。未重新跑850项或重复付费；不声称850项覆盖新增验收工具本身。

## 4. 实测、历史及失败分别保留

- [T05c1数值v2](../../experiments/m3-t05c1-scoped-regression.json)：8条已知任务满足预期，34次确认模型调用；6功能/2生命周期，不具独立实体留出。该实测为历史版本证据，当前数值v2受全量回归及原配置指纹测试约束，未重新付费测量。
- [T05c3b方法v2](../../experiments/m3-t05c3b-method-regression.json)：当前候选7条任务功能5/5、生成后撤回2/2，13次确认调用，0次schema错误；原始语料和已知重复不是独立质量集合。
- [T05c2b比较](../../experiments/m3-t05c2b-method-comparison.json)：规则比较4/4，保留不可比/同源时无变化指标和维修有效性为空；同文件的方法原式评分存在拒答混分，使用[事后审计](../../experiments/m3-t05c2b-outcome-review.json)的分项解释，不能宣称该文件全部通过。
- [T05a](../../experiments/m3-t05a-development-comparison.json)三组均完成5条控制，Agent没有完成率收益且增加调用；[T05b](../../experiments/m3-t05b-feedback-comparison.json)原Agent功能3/4、F02提前结束；[T05c3a](../../experiments/m3-t05c3a-method-diagnostics.json)方法功能1/4、生命周期0/1。失败原文/回执hash保留，不用新回归覆盖，也不计算未同时段重测的费用或效果提升百分比。

官方检查点探针、宿主死亡/子进程终止、BGE-M3真实HTTP/NumPy复算见[T02b1](M3-T02b1-verification.md)、[T02b3](M3-T02b3-verification.md)、[T03b2](M3-T03b2-verification.md)。它们来自各自冻结快照，部分共享代码与文档已有变化；审计结果列出source_drift_since_run并标historical_only，不冒称当前分支重新执行了这些HTTP实验。当前全量真实进程测试及方法真实索引/检索提供补充软件证据。
