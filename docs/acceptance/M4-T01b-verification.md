# M4-T01b 任务写交互验证

2026-11-01。本轮接入正式任务创建、回答/显式恢复与取消，承接[T01a只读工作台](M4-T01a-verification.md)及[M4设计](../11-m4-workbench-design.md)。完整M4及工厂试用准入仍未完成。

## 1. 交付行为

- inspector/engineer账号可创建任务；页面从授权采集读取当前版本，展示采样率、单位和确认状态。未确认输入不会被页面自动确认。
- 方法任务明确选择设备/部件范围；数值任务绑定采集版本；双数据比较只能使用该采集的已登记比较依据。当前方法表单不提供可选的设备资产限定，后续知识界面再补该筛选。
- 恢复携带当前expected_version、question_id和明确回答；有候选时只能选服务端提供的项。回答不改参数、不代替输入确认。取消需要明确勾选，终态任务不显示写操作。
- 在发送前将原命令、幂等键保存到按组织/账号隔离的sessionStorage。响应未确认时阻止新命令，仅允许用户显式重放原内容；切页/同账号重新登录可恢复跟踪，不自动提交。
- 409保留原版本/问题，先查询当前状态，再由用户确认是否结束被拒命令跟踪；不会自动换版本或生成新键。网络/5xx/403/404保留未知状态，401清空页面但保留本账号命令缓存。存储不可用或损坏时阻止发送。
- 迟到的写响应、读错误及组件卸载均有身份修订号/请求围栏；退出或切页不声称取消服务端任务。已确认受理后，详情读取失败不再当作创建未确认。

## 2. 实测结果

[前端回执](../../experiments/m4-t01b-frontend.json)：21项状态/传输测试通过（原12项＋新增9项）；vue-tsc、Vite生产构建通过，39份前端源文件指纹记录在回执中。新增覆盖原键/原内容重放、缓存恢复、重复点击、账号隔离、迟到结果、存储故障、401/403/404、409、取消版本以及已受理后的读取失败。

[浏览器回执](../../experiments/m4-t01b-browser.json)：10项实际页面流程通过；使用专用测试数据库、生成的合成账号与信号，真实规则API，Worker关闭以保留可观察的排队状态，未调用外部大模型。

| 检查 | 实际结果 |
| --- | --- |
| 回答恢复 | 等待输入确认的任务以当前问题/版本恢复，API202、页面排队；回答未自动确认输入 |
| 取消 | API200、页面已取消，终态写操作消失 |
| 方法创建 | 明确资料范围和勾选核对后创建，API202 |
| 数值创建 | 从实际授权记录读取当前版本后创建，API202 |
| 比较缺依据 | 没有登记依据时提交禁用 |
| 旧输入冲突 | 用正式参数修订API改变本轮合成采集版本，旧页面提交返回409，列表仍为10条 |
| 切页与重放 | 原命令内容恢复；显式重放仍409，不自动换用新输入 |
| 结束被拒跟踪 | 查询状态并明确勾选后才可结束 |
| 无写角色 | 实际admin账号未获inspector/engineer角色，无任务写控件 |
| 退出 | 清除表单/任务数据，登录页确认退出；API记录204 |

[当前桌面截图](../../experiments/m4-t01b-workbench.png)已目视检查；示例问题明确标为合成、不提交，未勾选时提交按钮禁用。

## 3. 覆盖边界及保留事项

本轮未知网络响应和迟到响应以真实前端模块的受控传输测试验证，未做浏览器断网故障注入。比较任务的成功提交及配置候选选择尚未新增浏览器正向用例；已有后端契约/执行测试保留，不能把本轮10项称为所有目标的完整端到端覆盖。窄屏最终视觉验收继续待补。

尝试另起私有执行助手时，先后被“运行时未启动”和“每库只允许一个API进程”的保护拒绝，均在领取任务前停止；因此不声称新建任务已在本轮再次跑完数值执行。现有M3执行、模型与诊断资格证据不改写。浏览器选择器最初用label精确定位下拉框超时；核对表单未提交后改用实际combobox角色完成验证。

退出的浏览器诊断出现ERR_ABORTED，但页面确认退出且服务日志记录204。409是本轮预期冲突，不按“浏览器零错误”表述。浏览器流程后仅补充了创建表单读取错误的身份修订号围栏，最终构建包含该修正。

本轮后端业务代码、迁移与默认rules不变，沿用M3既有850项全量基线，未重复运行该全量。合成数据、测试授权和本机API行为不构成现场效果、独立诊断评测或工厂试用事实。
