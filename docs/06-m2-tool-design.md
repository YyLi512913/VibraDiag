## 1. 交付目标和边界

M1回答“数据及基础数值能否可靠保存、计算、重读”。M2建立可供Agent选择调用的确定性轴承工具，回答“当前能观察到什么、哪些预期频率附近有成分、有什么歧义、哪些条件仍缺失”。

本阶段交付四类工具：analyze_envelope、calculate_bearing_frequencies、match_frequency_evidence、compare_measurements，以及有来源关系的fact/evidence对象和开发基线。工具可独立于LLM运行；M3再接正式Agent决策、RAG及持久执行。

支持范围仍是离线、定速稳态电机轴承。几何公式路径先实现外圈固定、内圈随目标轴转动、理想纯滚动的单列球轴承运动学；其他设计只在具备适用说明的频率系数路径中采用，否则标范围外。不能将这一路径泛化到所有滚动轴承。变速、双套圈转动、齿轮速比未核对、复杂行星传动、并发故障分离和保持架故障定类不在首发判断范围。

本轮不改M1的basic-v1，不新增故障分类模型或Embedding依赖，不声称“故障频率匹配=故障确诊”。模型对比仍按后续固定协议实施，不能把选库或一个合成正弦跑通写成效果评测完成。

## 2. 工具公共契约

服务端注入组织、操作者、权限、request_id、执行ID、输入快照、logical_call_key和预算。模型/客户端只提交业务ID及受限配置引用，不能传本地路径、SQL、代码、任意URL或自行声明checked_by。

| 字段 | 设计 |
| --- | --- |
| tool_execution_id、tool_name、tool_version | 实际执行及版本，不能用模型供应商tool_call_id替代 |
| input_fingerprint | 规范JSON的SHA256；含组织、输入revision/hash、上下文/目标参数版本、父结果、有效段及配置版本 |
| status | ok / unavailable / invalid_input / failed / cancelled；M2不提供取消API前不能伪造cancelled实现 |
| facts、artifact_refs、evidence_ids | 结构化数值、授权产物、通过来源检查登记的证据；数组不进入概要或模型消息 |
| missing_requirements、limitations | 缺参、适用范围、带宽/边界、分辨能力、混叠/重合等分开表达 |
| error_code、retryable | 明确错误；缺参数不能靠相同输入自动重试解决 |
| metrics | 开始/结束、实际耗时、依赖及算法/配置版本；不把未知成本记0 |

执行记录的running/completed/failed/interrupted与工具结果status分开：completed只说明一次执行/检查已结束，若status=unavailable，界面显示“条件不足，未执行该计算”，facts不填伪0。无权资源先返回401/403/404，不能借missing_requirements泄漏其他组织的数据。

语法/数值非法在受理前422；旧输入/确认或幂等冲突409；容量429；依赖503。满足业务结构但条件不足可登记unavailable决定和原因，不伪称已经生成频谱。M1的状态语义不变。

T02a已实现无HTTP/持久化的数值返回对象：ok/unavailable/failed，非法输入抛ToolInputError。它不生成执行ID、facts/evidence或权限结论；T02b再通过执行服务补齐公共契约。内部checked/qualification对象必须由服务端验证记录重建，不能作为前端自证资格的请求体。

### 3.3 探索计算与可用于诊断的观察

execution_mode分为exploratory与diagnostic_evidence。前者允许在数学频段合法时验证未知采集链的包络，始终标“探索计算，实际带宽未证实”，不可提升为已核实设备证据。后者必须核对有效采集带宽、相关上下文并采用已完成数值验证的配置；条件不足返回unavailable，保留M1结果。

“用户核对”“开发配置通过合成数值测试”“专业现场复核”分别记录，不相互替代。合成输入可对数学真值作测试证明，但不能被标为真实设备采集链已校准。

## 4. 理论特征频率

### 4.1 几何参数路径

输入Z为滚动体数整数，d为滚动体直径，D为节圆直径，α为接触角；同一长度单位，输入明确以mm保存，角以degree保存，公式内部转换radian。fr=rpm/60，q=(d/D)cosα。

实施补充：纯数值层接受明确的mm/m同单位比值以验证单位等价；T02b持久化归一到mm时另做有限性/转换范围检查。

外圈固定、内圈随轴旋转的理想运动学：

```text
FTF  = fr/2 * (1-q)
BPFO = Z*fr/2 * (1-q)
BPFI = Z*fr/2 * (1+q)
BSF  = D/(2*d) * fr * (1-q*q)
2BSF = 2*BSF
```

结果保存Hz、相对fr的阶次、参数来源、假设、适用范围和公式版本。FTF是辅助观察，不提供保持架故障定类；BSF与2BSF分开命名，2BSF不算第二种独立轴承参数。公式及恒速解调背景可对照[MathWorks原理示例](https://www.mathworks.com/help/predmaint/ug/Rolling-Element-Bearing-Fault-Diagnosis.html)。

严格校验：Z为3—64的整数且不是bool；0<d<D，0≤α<90°，所有值有限；超出首发配置范围不靠裁剪值通过。校验只证明参数符合当前公式输入约束，不证明几何来自真实型号。双列、复杂接触/载荷状态或不同参考运动不可套用该路径。

独立合成期望：Z=8、d=10mm、D=40mm、α=0°、rpm=1800，结果FTF=11.25、BPFO=90、BPFI=150、BSF=56.25、2BSF=112.5Hz。这是数学夹具，不是某个实际6205/6203型号的参数。

### 4.2 系数路径

采用c_FTF、c_BPFO、c_BPFI、c_BSF乘fr，分别要求明确的定义、单位（shaft order）、型号/变体/工况/旋转假设、出处定位/版本以及本次核对。来源若给的是2BSF或外圈相对转速系数，先完成显式映射，不能以字段名近似套用。

几何与系数为显式选择的两条路径；两组来源都存在且不同不能取平均。展示差异，选用哪一版须有记录；关键冲突未解决则unavailable。系数路径不从名称联网抓取，也不通过RAG命中直接改台账。

### 4.3 不确定性

转速值和不确定量同时影响匹配窗口。几何/制造商系数的适用公差也需有配置及来源；不凭空生成统计置信区间。M2结果是理想期望值，偏离不自动证明故障或滑移。

几何公差采用有来源的d/D/α区间保守传播：r=d/D的上下界分别用(d−ud)/(D+uD)、(d+ud)/(D−uD)，角区间须仍满足合法范围；由q=r·cosα的端点求FTF/BPFO/BPFI区间。BSF阶次写为1/(2r)−r·cos²α/2，在该范围随r递减、随α递增，据端点求区间。各阶次uncertainty取名义值到上下界的较大偏差；缺几何公差不能静默记0。系数资料已有适用误差界时直接采用其明确约定，不把经验标准差当成最大偏差。

## 5. 包络算法与有效段

### 5.1 候选配置envelope-sos-hilbert-v1

| 配置 | 初版约定 |
| --- | --- |
| 输入 | 完整原始文件，沿用1024—1000000点及32MiB；不删除冲击、不限幅、不插值、不重采样 |
| 单位与尺度 | g按9.80665转m/s²；沿用缩放与有限数值检查，不能让数值溢出/下溢产生假0 |
| 去均值 | 带通前去全文件均值；原文件及M1基础指标不变 |
| 滤波器 | scipy.signal.butter(N=4, [low,high], btype=bandpass, fs=fs, output=sos) |
| 阶数 | 4是原型阶数；单次带通总阶数8、4个SOS；前后向响应为abs(H)^2，不能把全过程称为“4阶因果滤波” |
| 相位/填充 | sosfiltfilt，padtype=odd，显式padlen；离线零相位，不是实时滤波 |
| 包络 | 滤后信号两侧reflect延拓G点，Hilbert长度明确=N+2G，不另补零；abs解析信号后去掉延拓，再裁去原始两侧G点 |
| 包络谱 | 对保留包络去均值、周期Hann、相干增益补偿、单边峰值幅度；DC及偶数Nyquist不翻倍 |
| 输出单位 | 包络及包络谱峰值幅度为m/s²；不叫PSD/功率，也不与原始加速度幅度谱混称 |

SOS/前后向/Hilbert行为分别参考[SciPy butter](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.butter.html)、[sosfiltfilt](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html)、[hilbert](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.hilbert.html)。官方网页当前显示1.18，实际环境为锁定的SciPy1.17.1；本轮已在本地核对函数签名并运行探查，没有升级依赖。

滤波器的幅频响应必须保留：Butterworth临界频率是单次约−3dB位置，前后向后临界幅值约0.5（−6dB）。窗增益补偿不补偿带通增益；不能把带边衰减解释成故障幅值减小。新带宽/阶数须新配置，模型不能自行换滤波器后沿用旧版本。

### 5.2 边界规则

对S个SOS，使用显式 `P=3*(2*S+1-min(count(b2==0),count(a2==0)))`，要求N≥P+2。提取各段分母极点半径的最大值r，须0<r<1。

候选保护区：`G=max(3*P,ceil(2*log(1e-6)/log(r)),ceil(fs/low))`。这是有版本的保守启发式，不是所有IIR尾项和Hilbert非局部误差的数学上界；不能仅凭这个公式宣布任意频段已合格。

原始N点经滤波与Hilbert之后，明确保留原始索引 `[G,N-G)`，M=N−2G；包络相对原始起点为G/fs，有效末点为(N−G−1)/fs，有效时长M/fs，包络谱bin间隔fs/M。M1整文件指标/时长不能被替换成这个有效段。

保护区不得静默压小。初版要求G≤65536、Hilbert长度N+2G≤1200000、M≥1024；不足时unavailable。modulation_low_hz>0，保留时长至少能观察该下限10个周期。展示明确被舍弃的边界与原因，原CSV始终保留，边界冲击仍可在M1原始指标/波形找到。

### 5.3 频段与发布条件

数学上要求0<low<high<fs/2；调制观察范围须0<fmin<fmax，fmax≤(high−low)/2且低于包络Nyquist。这个范围限制是首版保守约束，不证明实际载波位于平坦通带或传感器覆盖足够。

工程师可明确设置探索频段并记录依据；进入diagnostic_evidence还须处于有依据的有效采集带宽，并使用经过该采样率/边界/信号集验证的配置。初版不做自动谱峭度选带；Agent只能选择已经授权的profile_id，不能凭观察到的峰反复调带直到出现预期结果。

每次profile保存SOS系数/摘要、滤波幅频响应、P/G及延拓/窗口规则。配置资格至少覆盖AM、无调制、边界激励、两载波拍频、弱信号、非法/窄频段、长度与尺度测试。邻近合法频段的敏感性检查独立登记；没有检查不等于结果稳定。

### 5.4 T01设计探查（历史）

本轮仅运行[探查脚本](../experiments/m2-design/probe_envelope.py)，结果见[原始JSON](../experiments/m2-design/probe-results.json)：fs=12000、带通2000—4000Hz、P=27、G=161；有效48000/48001点，3000Hz载波，峰值2、调制深度0.25，理论包络调制幅值0.5。

两种长度的目标bin幅值误差约1.0e−8m/s²；保留段逐点包络仍存在约0.009—0.011m/s²的最大边界偏差。无调制对照在10—500Hz内的最大谱幅值约1e−12—1e−11m/s²。谱上单点吻合不能证明边界完全消除；profile_qualified仍为false。

该探查当时只检查候选流水线和量纲，未实现正式工具或完整拒绝分支。T02a现已实现数值模块并新增83项测试，见[实施记录](acceptance/M2-T02a-verification.md)；服务、公开数据验证与现场标定仍未完成。这些数据已用于设计/开发，不能称未见测试集。

数值结果evidence_preconditions_satisfied仅表示对传入作用域声明的数值核对；真实来源/资格/权限必须由T02b查证。频率结果uncertainty_complete只说明边界信息完整，不保证谱可分辨或已经匹配；缺公差仍保留名义值但不填零区间。

## 6. 匹配与歧义

结项修订：新执行采用frequency-matching-v2，仅多个通过既定幅度比/显著度阈值的峰产生多峰歧义；候选仍保留。matching-v1是阈值配置名，与算法版本分开。旧v1结果不重算，修复前回执和当前基线见[M2总验收](acceptance/M2-acceptance.md)。

### 6.1 搜索目标和窗口

目标引用同一context的理论结果，必须能追溯到同一measurement_revision。BPFO/BPFI默认检查1—5次谐波；BSF检查1—4次，其中2BSF只是BSF二次谐波的显式别名，不增加独立证据数。FTF辅助显示，不产生保持架类别。

检查BPFO/BPFI周围±1/±2fr边带、BSF/2BSF周围适用的FTF边带；这些是待核查模式，不是“有边带一定是某故障”的规则。负频率、超出观察范围、与其他目标重复的项分别记录，不填成未命中0。

令Δf=fs/M。中心c·fr的h次目标窗口候选半宽：

```text
epsilon = 2*delta_f
        + h*abs(c)*rpm_uncertainty_rpm/60
        + h*fr*coefficient_uncertainty_absolute
        + h*coefficient_uncertainty_absolute*rpm_uncertainty_rpm/60
        + abs(target_hz)*slip_allowance_relative
```

边带按各个系数/间隔不确定量的绝对贡献求保守和，不能因正负号抵消而缩小未知量。2Δf参考Hann主瓣的bin尺度，仍不是完整频率估计置信区间。slip_allowance须明示来源/适用机制；开发配置可采用1%候选值，但不称全行业通用滑移界限。

交叉项保留系数与转速不确定量乘积；实现可直接用正值区间乘积求目标上下界及最大偏差，再加bin/滑移项。只有来源明确为精确合成真值的量可以采用零不确定量。

候选开发配置限制epsilon≤目标频率5%，超过则resolution_limited，不能强行夹到5%继续给确定支持。真实参数缺不确定量时不默认为0；可返回理论值/探索观察，诊断匹配unavailable。目标窗口超出可分析范围不静默裁剪后称无峰。

### 6.2 峰和局部参考

在完整有效观察谱上找局部峰，再按搜索窗口筛选，避免先切窗口把边界bin漏掉；不将最近bin直接记作命中。无相邻信息的DC/Nyquist边界点不作为普通局部峰处理。

候选峰记录bin索引、Hz、幅值、频差、窗口、局部prominence。最多返回8个候选；按幅值/距离/较低bin确定展示顺序。一个窗口内存在多个达到幅度比/显著度阈值的候选时标multiple_peaks，不把最高峰强行定类。

局部参考窗半宽W=max(10Δf,4epsilon)，排除目标保护区max(2Δf,epsilon)以及其他已登记目标/干扰窗口。参考至少20个bin；不足则noise_reference_insufficient，不以0代替。使用参考幅度中位数，不称已测传感器噪声或统计噪声功率。

开发阈值候选：峰/参考幅度比≥4，prominence/参考幅度比≥3。比值定义为幅度比，若展示dB使用20log10，不误用功率10log10。参考中位数为0时，仅允许使用64·float64_eps·全谱最大幅值的数值地板，并标reference_floor_applied；这是计算限制，不是物理量程/噪声标定。全谱0或地板无法表示时返回无动态信息/数值范围限制，不输出Inf比值。

这些阈值在开发数据上验证后版本化冻结；正式留出集不能用于反复调阈值。幅度比不是故障概率或诊断置信度。

实施补充：T03a以已传播frequency_hz_interval求出的uncertainty_hz构造窗口，保留交叉项；边带绝对贡献求和。prominence固定41-bin局部窗；原始载波筛查阈值/预算与未检查项见[T03a记录](acceptance/M2-T03a-verification.md)。0滑移且精确参数时，既定参考窗可能不足20bin，明确返回noise_reference_insufficient，不自动扩窗。

### 6.3 冲突检查与结果状态

至少区分observed_support、no_observed_support、ambiguous、not_evaluable；仅指该窗口/模式的观察，不是故障类别判决。

- 以相同输入基础谱和包络谱检查1—10倍fr附近成分；与目标窗口重合时保留转频/倍频混淆。
- 多个目标窗口重合或共享同一峰时组成overlap_group，共用peak_id；不能将同一峰分别计成多个独立支持。
- 同一带内两个载波的拍频可能形成包络峰；原始带内谱未核查时confounder_checks_complete=false，不能宣称已排除该解释。
- 邻频、弱峰、局部参考不足、宽容差、滤波敏感或不同参数来源冲突分别记录。未检查的项目标未知，不能写“无干扰”。
- no_observed_support只表示当前有效段/频带/阈值下未观察到支持；不排除全部轴承故障。峰存在也不足以定位实际缺陷部件。

M2输出支持/缺失/歧义的事实材料。M3再用经版本化验证的每类必要证据规则决定是否允许诊断草稿；不能用“至少两个ID”“最高匹配分”替代物理适用性、相关性及冲突检查。

## 7. 前后比较

正式比较要求：两份数据的组织/访问范围有效，设备/目标部件/测点/方向相同且采集顺序可核对；单位可可靠换算；采集带宽、采样/片段、时域/谱处理及包络profile可比；转速和负载均有本次依据与可比性判断。

初版开发容差可配置为转速差不超过明确不确定量之和或参考转速1%的较大者，负载必须同物理表示及有界差异依据；这不是已验证工业通用标准。缺负载、方向/时间未知、变量负载表示不能转换、fs/带宽不同而缺乏验证时，输出not_comparable及原因。仍可分别显示两份分析，不给正式改善百分比或维修有效判断。

可比时计算after−before；百分比仅在before可表示且非0时计算，并在接近数值分辨率/实际测量不确定量时标限制。before=0时百分比null，不加任意小常数得到巨大“改善率”。同一次采集的重复导入/派生段标related_or_same_acquisition，不作为独立维修前后采集。

两个输入各自采用当前明确版本；初版不新增隐式“按旧参数重算”入口。M2只建立比较工具，正式复测/维修有效验证及工单关联仍在M5。

T04a实施补充：当前纯数值核心采用comparison-v1，要求同点数/采样率、同目标轴承参数版本、已核对采集开始时间与顺序、同采集链指纹/有效带宽、来源明确的稳态转速和负载参考/绝对容差。已支持明确负载单位换算及g/SI规范指标；均值只报告有单位差值，不报告跨零易误导百分比。可选包络须两侧成功、同配置和有效索引，并用完整包络计算均值/RMS/峰值。相关/重复采集、不可比及不可表示数值分别返回；测量不确定量未知/数值分辨能力不足显式标限制。详见[T04a](acceptance/M2-T04a-verification.md)。

T04b已新增不可变comparison_declarations，通过工程师受控CLI登记采集根、采集链/时间与负载依据及容差，配置hash由服务端生成；公开请求不接受checked。双输入运行已接持久化、双侧授权/确认、父hash/规范内容排重、恢复与最小页面，见[T04b](acceptance/M2-T04b-verification.md)。比较始终不自动判断维修有效，统计独立性仍标未建立。
