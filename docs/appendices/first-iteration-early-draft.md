## 2. 第一轮目标

工程师能够导入一段单测点、单方向、均匀采样的加速度信号，明确填写采样率与单位；系统检查数据，计算时域特征与幅度谱，返回可追溯的分析结果。

这轮证明文件导入、计算和追溯链路可靠，不输出轴承故障诊断或维修建议。Agent 后续调用这套确定性工具。

完成顺序：数据契约 → Python 分析核心 → FastAPI 接口 → 最小分析页面 → 验收记录。

## 3. 输入契约 v0.1

首发支持 UTF-8 CSV，必须且仅有一列 `value`，每行一个有限数值。其他格式与多列文件后续通过适配器转换，不猜测列含义、不自动跳过表头行。

| 字段 | 必填 | 约束 |
| --- | --- | --- |
| file | 是 | CSV；第一轮限制 10 MiB，超限明确拒绝 |
| sampling_rate_hz | 是 | 有限正数，禁止默认填充 |
| acceleration_unit | 是 | `g` 或 `m/s2`；g 按 9.80665 转换为 m/s²，保留原始单位 |
| asset_ref | 否 | 用户提供的设备标识，不作为真实设备存在的证明 |
| measurement_point | 否 | 测点标识，缺失标记 unknown |
| direction | 否 | 测量方向，缺失标记 unknown |
| rpm | 否 | 有限正数；本轮不用于故障分类 |
| acquired_at | 否 | 带时区的采集时间；缺失保留为空，不用上传时间代替 |

基础分析至少 1024 点，最多 1000000 点。此上下限是第一轮工程约束，不代表满足所有故障分析任务。实际记录时长、分析长度与频率分辨率必须展示。

轴承型号和几何参数暂不必填；缺失时不生成轴承理论特征频率。

## 4. 数据质量行为

- 空文件、重复/错误列名、非数值、NaN、Inf、少于最少点数、超限均返回明确错误。
- 不删除高幅值点，不自动截断、重采样或插值；不把异常点删除后当作原时间轴。
- 恒定信号允许计算 RMS 与频谱，产生质量提示；无法定义的峭度、峰值因子返回 null 及原因。
- 缺少传感器量程时不能断言是否削顶或超量程；高幅值不直接等于故障。
- 明确标识采集参数为用户提供，系统暂不能验证传感器标定与真实采样时钟。

## 5. 计算契约

所有计算由代码完成，保存算法版本和配置。

| 项目 | 第一轮定义 |
| --- | --- |
| 原始 RMS | 对换算单位后的原始信号计算，包含 DC |
| AC RMS | 对去均值信号计算 |
| 峰值 | 原始信号绝对值最大值 |
| 峰值因子 | 原始峰值 / 原始 RMS；零 RMS 返回 null 与原因 |
| 峭度 | 原始信号的总体 Pearson 峭度，非超额峭度；零方差返回 null |
| 幅度谱 | 去均值、周期 Hann 窗、rFFT，按窗相干增益做单边幅值标定，DC/Nyquist 不翻倍 |
| 频率轴 | `k * sampling_rate_hz / N`；报告 bin 间隔 fs/N；不将它等同于实际可分辨能力 |
| 分析长度 | 本轮使用整个输入，不隐藏截取片段；超限拒绝而非静默截断 |

第一轮暂缓包络谱。后续单独确定带通选频、滤波配置、边界处理与验证方法后再加入。

## 6. 输出与追溯

每次分析生成唯一 analysis_id，记录：原文件 SHA256、文件大小、输入参数、样本数、时长、算法版本、处理步骤和质量提示。

上传时间和采集时间分别存储。原始文件不因预处理被覆盖；对同一文件重复分析生成独立分析记录，但文件可按校验值去重。

原始文件放在服务控制的目录，使用生成 ID 命名，不拼接用户文件名为存储路径；原文件名仅作为显示元数据保存。

第一轮分析结果使用本地 SQLite 保存索引与参数，原始文件/结果文件本地存储。通过存储接口隔离，后续随业务数据模型引入 PostgreSQL；当前不启动 Redis、pgvector。

第一轮只监听本机，不作为已具备账号权限的共享部署版本。

建议接口：

- `POST /api/v1/analyses`：multipart 文件与元数据，创建分析。
- `GET /api/v1/analyses/{analysis_id}`：结果与可追溯参数。
- `GET /health`：基础运行状态。

超限返回 413；输入错误返回 422；不存在返回 404；内部错误返回 500 和可检索的请求 ID，不向页面暴露堆栈。

## 7. 第一轮验收

1. 4096 Hz 采样、4096 点、128 Hz、幅值 1 m/s² 的正弦信号：RMS 为 1/√2，幅度谱主峰 128 Hz、幅值约 1。具体容差随数值实现记录，接近零时使用绝对容差。
2. 增加固定 DC 偏置：原始 RMS 与 AC RMS 符合各自定义；频谱按约定去均值，不影响原始特征计算。
3. 相同物理信号分别以 g 和 m/s² 输入，换算后的结果在容差内一致。
4. 测试奇偶长度、零信号与 Nyquist 分量，避免单边幅值翻倍错误。
5. 非数值、NaN/Inf、零采样率、缺少单位、短信号和超限文件得到预期错误，不返回空成功。
6. 导入已记录来源的 CWRU 105 DE 信号，展示结果、单位、采样率和校验值；这只验收分析链路，不据此统计故障准确率。
7. 页面能完成真实上传、查看结果与质量提示；刷新后可按 analysis_id 读取；前后端请求端到端通过。
8. 服务重启后仍可读取已有分析；未经用户显式删除，不清理原始文件。
