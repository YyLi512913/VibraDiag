# 01 需求规格

> 版本：v0.1（骨架，待确认结构）
> 状态：第 2 步产出物
> 上游：00-project-charter.md v1.0
> 说明：本版只覆盖三个核心场景的 9 条用户故事与验收标准，结构确认后再铺全量功能与非功能需求

## 1. 角色

| 角色 | 职责 | 主要界面 |
| --- | --- | --- |
| 点检员 | 现场采集振动数据、描述异常现象 | 对话窗口 |
| 维修工程师 | 查看证据与结论、确认或修改、执行维修 | 诊断工作台 |
| 设备主管 | 审批高优先级工单、查看设备健康趋势 | 设备总览与工单 |

## 2. 术语

| 术语 | 定义 |
| --- | --- |
| 测点 | 加速度传感器安装位置，驱动端 DE / 风扇端 FE |
| 工况 | 转速与负载的组合，诊断结论必须绑定工况 |
| 特征频率 | BPFO 外圈、BPFI 内圈、BSF 滚动体、FTF 保持架 |
| 证据 ID | EV-xxx，唯一标识一条证据，可解析到信号片段或标准条款 |
| 诊断会话 | 一次现象描述到结论的全过程，可跨请求恢复 |

## 3. 用户故事与验收标准

### 场景 A：现象诊断

**US-A1 多轮澄清**

作为点检员，我希望用自然语言描述异常，系统自动抽取设备、测点、时间窗、工况，缺失时逐项追问，以便不用记表单字段。

- 给定「3 号电机振动大，夜班明显」，当缺少测点与转速时，系统应追问且单轮不超过 2 个问题
- 给定用户补充「驱动端、1480 转」，系统应回填槽位并复述确认
- 给定四个槽位齐全，系统应直接进入取数，不得重复追问

**US-A2 特征计算**

作为维修工程师，我希望系统自动拉取振动数据并计算 RMS、峭度、包络谱与特征频率幅值，以便我不必手工做 FFT。

- 给定 12k 采样率数据，系统应在 5 秒内返回特征摘要（RMS、峭度、峰值因子、四个特征频率处幅值）
- 给定数据缺失或采样率不足，系统应明确报错并给出可选时间窗，不得用空数据继续推理
- 给定同一设备同一时间窗，重复计算结果的相对误差应小于 1e-6

**US-A3 假设与取证**

作为维修工程师，我希望系统给出 2–3 个候选故障假设，逐条取证后收敛，以便结论有依据而不是拍脑袋。

- 给定特征摘要，系统应输出候选假设、每个假设所需证据、当前支持度
- 给定需要补充证据，系统应调用对应工具（谐波检查、趋势对比、历史工单），并记录调用参数
- 给定证据充分，系统应输出 Top-1 结论与置信度；给定证据冲突，应进入拒答分支

### 场景 B：证据化报告

**US-B1 证据链**

作为维修工程师，我希望每条结论都绑定证据 ID，并能点开查看原始频谱或标准条款，以便判断结论是否可信。

- 给定一条结论，其绑定证据 ID 数量应不少于 2 条，且每个 ID 可解析到具体数据片段或条款
- 给定证据 ID，点击应展示对应频谱、特征值与采集参数
- 给定结论未绑定证据，系统应禁止输出，保证无证据结论率为 0

**US-B2 拒答**

作为设备主管，我希望证据不足时系统明确说「无法确定」并说明缺什么，以便不误导维修决策。

- 给定证据不足场景，系统应拒答而非给出故障结论
- 给定拒答，应列出缺失证据与建议补测项（延长采样、增加测点、补充工况）
- 给定拒答，系统不得生成工单

**US-B3 诊断报告**

作为维修工程师，我希望得到结构化报告：现象、数据、特征、证据链、结论、建议、紧急程度。

- 报告应包含 7 个固定区块，缺一不可
- 建议应包含动作（更换/复检/调整）、时限、所需备件
- 紧急程度应为 4 级之一，且与 ISO 10816 振动烈度区间映射一致

### 场景 C：工单闭环

**US-C1 人工确认**

作为维修工程师，我希望确认或修改结论后才生成工单，以便模型不能直接触发写操作。

- 给定未确认状态，工单接口应拒绝创建
- 给定确认，应签发一次性确认令牌，令牌与诊断记录、动作哈希绑定
- 给定重复提交同一令牌，应幂等返回首次结果，不产生第二张工单

**US-C2 审计**

作为设备主管，我希望每次诊断可追溯：谁发起、用了哪些数据与工具、模型版本、确认人。

- 审计记录应包含会话 ID、数据时间窗、工具调用列表、模型与 prompt 版本、确认人、时间
- 审计记录只可追加，不可修改
- 给定一次诊断，应能在一次查询内还原完整链路

**US-C3 复测闭环**

作为维修工程师，我希望维修后回填复测数据，对比维修前后特征，以便验证诊断是否有效。

- 给定工单完成，系统应提示上传或关联复测数据
- 给定复测数据，应输出维修前后 RMS、峭度、特征频率幅值对比
- 给定复测仍异常，应允许基于同一会话开启二次诊断，并保留历史记录

## 4. 本期不做

- 实时采集与在线监测告警
- PLC / SCADA / MES 集成
- 齿轮箱、汽轮机、电气故障诊断
- 自动停机、自动派工、自动采购
- 多租户、计费、自助注册
