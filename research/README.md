# 本地调研工作区

本目录用于本机保存第三方仓库、下载数据和临时验证文件，除本说明外不提交至Git。

项目开发代码位于`backend/`和`frontend/`，正式设计与调研结论见[开源验证记录](../docs/appendices/open-source-verification.md)，数据来源与使用边界见[datasets](../datasets/public-data-v1/README.md)。项目自己的可复现评测脚本位于`backend/scripts/`，验证回执位于`experiments/`。

历史回执中的调研目录和本机路径保留当时含义，不表示第三方仓库或原始研究数据随本项目发布。运行当前正式工作台不依赖这些本地第三方检出目录。
